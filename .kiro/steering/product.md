# PW Canvas 产品概述

PW Canvas 是一个 WordPress 插件，为电商网站提供在线产品定制功能。它使客户能够直接在网页浏览器中使用强大的画布编辑器设计和定制产品。

## 核心功能

- **在线画布设计器**: 基于 Fabric.js 构建的 2D 画布编辑器，用于产品定制
- **产品变体管理**: 支持颜色、尺寸和其他产品变体
- **WooCommerce 集成**: 与 WooCommerce 深度集成，支持购物车和结账功能
- **设计模板系统**: 自定义文章类型 `pw_design` 用于管理设计模板
- **实时预览**: 实时预览和导出功能
- **API 集成**: 与 Promowares API 进行外部数据集成

## 目标应用场景

- 定制服装和商品设计
- 促销产品定制
- 按需打印产品配置
- 个性化礼品创作
- 企业品牌应用

## 依赖要求

- WordPress 环境
- WooCommerce 插件（必需）
- Flamingo 插件（必需）
- PHP 5.6+ 兼容性
- 现代网页浏览器支持前端功能
