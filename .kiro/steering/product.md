# PW Canvas - WordPress 插件

PW Canvas 是一个与 WooCommerce 集成的 WordPress 插件，提供自定义产品设计和画布功能。该插件采用现代化的Vue 3 + Pinia架构，支持多数据源聚合和实时产品定制。

## 核心功能

- **产品定制**: 交互式画布，支持产品设计、颜色选择、渐变和自定义颜色
- **现代化前端**: Vue 3 + Pinia + Axios 技术栈，提供响应式用户体验
- **WooCommerce 集成**: 与 WooCommerce 无缝集成，支持产品管理和购物车功能
- **设计库**: 设计资源和分类的管理系统，支持层级分类和标签
- **API 聚合**: BFF模式的API聚合系统，整合Promowares API和Mock API数据
- **管理后台**: 自定义Promoware管理界面，集成产品同步、缓存管理和设计管理
- **模块化架构**: 前台采用模块化设计，支持CDN加载和组件化开发

## 设计管理系统

### 自定义文章类型
- **pw_design**: 核心设计资源文章类型
  - 支持标题、内容编辑器、特色图片、摘要
  - 包含自定义字段和修订历史
  - 支持评论功能
  - SEO 友好的固定链接结构 (`/pw-design/`)
  - 通过自定义Promoware菜单管理，不在主菜单显示

### 分类系统
- **pw_design_category**: 层级设计分类
  - 支持父子级分类结构
  - 在管理列表中显示分类信息
  - SEO 友好的分类页面 (`/pw-design-category/`)
  - 支持 REST API 访问
  - **自定义元数据**: 分类类型、导出排除、图层深度、缩放模式
  - **AJAX管理**: 支持添加、更新、删除分类的实时操作
  
- **pw_design_tag**: 设计标签系统
  - 非层级标签结构
  - 支持热门标签显示
  - 逗号分隔的标签输入
  - 标签建议功能
  - SEO 友好的标签页面 (`/pw-design-tag/`)

### 管理界面集成
- **Promoware主菜单**: 统一的管理入口
- **Dashboard**: 产品同步、API连接、缓存管理
- **Design Library**: 设计资源浏览和管理
- **分类管理**: 支持AJAX的分类增删改操作
- **产品请求**: 集成Flamingo插件的产品请求表单

### 功能特性
- **内容管理**: 完整的 WordPress 内容管理功能
- **搜索集成**: 设计内容包含在站点搜索中
- **权限控制**: 基于 WordPress 标准权限系统
- **国际化支持**: 完整的多语言支持 (pw-admin 文本域)
- **REST API**: 分类和标签支持 REST API 访问
- **图片API**: 专用的设计图片获取端点

## 产品页面现代化架构

### Vue 3 + Pinia 技术栈
- **Vue 3**: 现代化响应式前端框架
- **Pinia**: 状态管理，替代Vuex
- **Axios**: HTTP客户端，处理API调用
- **CDN加载**: 通过CDN动态加载依赖，提高性能

### 组件化设计
- **ColorVariants**: 颜色变体选择器
- **ProductQuantity**: 数量选择器，支持批量折扣
- **ProductPriceInfo**: 实时价格计算显示
- **AddToCart**: 添加到购物车功能
- **CheckboxOptions**: 复选框选项组件
- **ProductAccessories**: 产品配件选择器

### API聚合系统
- **BFF模式**: Backend for Frontend，单一聚合端点
- **多数据源**: 整合Promowares API、Mock API、WooCommerce数据
- **缓存机制**: 30分钟缓存，提高性能
- **业务逻辑**: 服务端计算产品可定制性、价格等信息

### 画布功能
- **Fabric.js**: HTML5 Canvas图形库
- **图层管理**: 支持图层显示/隐藏、锁定、删除、复制
- **拖拽排序**: 图层顺序调整
- **3D模型**: 支持3D产品预览
- **导出功能**: 支持设计导出和PDF生成

## 目标用例

该插件专为销售可定制促销产品的电商店铺设计，提供：
- **B2B客户**: 批量定制和折扣计算
- **个人客户**: 产品个性化设计
- **管理员**: 产品同步、设计管理、订单处理
- **开发者**: 模块化架构，易于扩展和维护
