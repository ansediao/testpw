# PW Canvas - WordPress 插件

PW Canvas 是一个与 WooCommerce 集成的 WordPress 插件，提供自定义产品设计和画布功能。该插件允许用户通过交互式画布界面使用颜色、渐变和设计元素来定制产品。

## 核心功能

- **产品定制**: 交互式画布，支持产品设计、颜色选择、渐变和自定义颜色
- **WooCommerce 集成**: 与 WooCommerce 无缝集成，支持产品管理和购物车功能
- **设计库**: 设计资源和分类的管理系统
- **API 集成**: 连接外部 Promoware API 进行产品同步
- **管理后台**: 自定义管理界面，用于管理设计、分类和产品设置

## 设计管理系统

### 自定义文章类型
- **pw_design**: 核心设计资源文章类型
  - 支持标题、内容编辑器、特色图片、摘要
  - 包含自定义字段和修订历史
  - 支持评论功能
  - SEO 友好的固定链接结构 (`/pw-design/`)
  - 不在主菜单显示，通过自定义管理界面访问

### 分类系统
- **pw_design_category**: 层级设计分类
  - 支持父子级分类结构
  - 在管理列表中显示分类信息
  - SEO 友好的分类页面 (`/pw-design-category/`)
  - 支持 REST API 访问
  
- **pw_design_tag**: 设计标签系统
  - 非层级标签结构
  - 支持热门标签显示
  - 逗号分隔的标签输入
  - 标签建议功能
  - SEO 友好的标签页面 (`/pw-design-tag/`)

### 功能特性
- **内容管理**: 完整的 WordPress 内容管理功能
- **搜索集成**: 设计内容包含在站点搜索中
- **权限控制**: 基于 WordPress 标准权限系统
- **国际化支持**: 完整的多语言支持 (pw-admin 文本域)
- **REST API**: 分类和标签支持 REST API 访问

## 目标用例

该插件专为销售可定制促销产品的电商店铺设计，客户可以在购买前使用颜色、设计和自定义图形来个性化产品。
