ES Modules (ESM) 浏览器原生模块系统

无需打包工具，浏览器原生支持的 JavaScript 模块化方案

什么是 ESM？ ES Modules 是 ECMAScript 2015 (ES6) 定义的官方模块化标准。 现代浏览器已原生支持 <script type="module">，可以直接使用 import 和 export 语句， 无需 Webpack/Rollup 等打包工具。

关键特性： defer 默认启用 · 严格模式 · 模块作用域 · 循环依赖支持 · 仅执行一次
文件结构
demos/cdn/esm/
├── module.html ← 主页面（你在这里）
├── math.js named exports 数学工具函数
├── greeting.js default + named 多语言问候
├── weather.js all named 天气数据（动态导入）
├── display.js named exports UI 渲染辅助
└── app.js entry point ← 主入口模块
ESM 语法示例

具名导出 Named Export

// math.js
export const PI = 3.14;
export function add(a, b) {
    return a + b;
}

具名导入 Named Import

// app.js
import { add, PI }
    from './math.js';

add(PI, 2); // 5.14

默认导出 Default Export

// greeting.js
const dict = { zh: '你好' };
export default dict;

默认 + 具名导入

// app.js
import dict, { translate }
    from './greeting.js';

dict.zh;      // 你好
translate('世界'); // 你好, 世界!

动态导入 Dynamic Import

const mod =
  await import('./weather.js');
mod.getDefaultCity();
// Beijing

导入重命名 Rename

import { translate as t }
    from './greeting.js';

t('World', 'en');
// Hello, World!
