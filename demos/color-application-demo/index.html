上色原理说明

本演示展示了如何使用 Fabric.js 对图像图层进行纯色覆盖处理，其核心原理如下：

  • 图像数据读取：通过创建临时画布并绘制原始图像，获取其 ImageData 数据。
  • 像素遍历与判断：遍历每个像素点（每4个值为一组：R, G, B, A），判断其是否为非透明区域（alpha > 10）。
  • 颜色替换：对于所有非透明像素，将其 RGB 值替换为选定的颜色值，保持 Alpha 通道不变以保留原图透明度信息。
  • 重新渲染：将修改后的图像数据转换为 Data URL，并用 Fabric.js 创建新的图像对象替换原有图层。
  • 叠加图层保护：每次重新上色后，确保 Overlay Layer 保持在最上层，不影响 Base Layer 的视觉效果。

技术要点：该方法利用了 HTML5 Canvas 的 getImageData 和 putImageData API 来操作像素级别数据，从而实现动态变色功能。
