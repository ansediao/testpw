# 多视图导出图片逻辑

## 概述

本文档详细说明了 `pw-canvas` 项目中多视图导出图片功能的实现逻辑和工作流程。

## 核心函数

### `exportAllViewsAsImages()` - 主导出函数

**位置：** `public/js/main.js`

**功能：** 遍历所有视图，逐一切换并捕获每个视图的画布内容，最终在新窗口中展示所有导出的图片。

## 工作流程

### 1. 初始化阶段

```javascript
// 获取当前激活视图ID，用于最后恢复
const originalActiveViewId = designStore.activeViewId;

// 获取所有视图列表
const allViews = designStore.views;

// 初始化结果数组
const exportedImages = [];
```

### 2. 视图遍历与切换

对每个视图执行以下步骤：

#### 2.1 视图切换
```javascript
// 手动触发视图容器的显示/隐藏
document.querySelectorAll('.view-container').forEach(container => {
    container.style.display = 'none';
});

const targetContainer = document.querySelector(`#view-${view.id}`);
if (targetContainer) {
    targetContainer.style.display = 'block';
}
```

#### 2.2 全局Canvas引用更新
```javascript
// 更新全局canvas引用
const canvasInstance = designStore.canvases[view.id];
if (canvasInstance) {
    window.canvas = canvasInstance;
}
```

#### 2.3 状态清理
```javascript
// 取消所有视图上元素的选中状态
Object.values(designStore.canvases).forEach(canvasInstance => {
    if (canvasInstance && canvasInstance.discardActiveObject) {
        canvasInstance.discardActiveObject();
        canvasInstance.renderAll();
    }
});
```

### 3. 等待机制

```javascript
// 等待视图切换和渲染完成
await new Promise(resolve => setTimeout(resolve, 500));
```

**说明：** 500ms 的延迟确保：
- DOM 更新完成
- Canvas 重新渲染
- 所有异步操作完成

### 4. 图像捕获

#### 4.1 调用捕获函数
```javascript
const imageDataUrl = await captureCanvas(false);
```

#### 4.2 `captureCanvas()` 函数逻辑

**位置：** `public/js/export.js`

**核心步骤：**

1. **获取画布元素**
   ```javascript
   const { colorCanvas, shadowCanvas } = getActiveCanvasElements();
   const fabricCanvas = getActiveCanvas();
   ```

2. **创建临时画布**
   ```javascript
   const tempCanvas = document.createElement('canvas');
   tempCanvas.width = currentColorCanvas.width;
   tempCanvas.height = currentColorCanvas.height;
   ```

3. **图层合成顺序**
   - **白色背景层**
   - **阴影层** (`shadowCanvas`)
   - **颜色层** (`colorCanvas`)
   - **主画布内容** (Fabric.js canvas)
   - **边界区域**（可选）

4. **Fabric.js 画布处理**
   ```javascript
   // 强制渲染以确保最新内容
   fabricCanvas.renderAll();
   
   // 转换为图片并绘制
   const fabricImage = new Image();
   fabricImage.onload = function() {
       tempCtx.drawImage(fabricImage, 0, 0, tempCanvas.width, tempCanvas.height);
   };
   fabricImage.src = fabricCanvas.toDataURL('image/png');
   ```

### 5. 结果收集

```javascript
exportedImages.push({
    viewId: view.id,
    viewName: view.name || `视图 ${view.id}`,
    imageData: imageDataUrl,
    timestamp: new Date().toLocaleString()
});
```

### 6. 状态恢复

```javascript
// 恢复到原始激活视图
if (originalActiveViewId) {
    // 切换回原始视图
    document.querySelectorAll('.view-container').forEach(container => {
        container.style.display = 'none';
    });
    
    const originalContainer = document.querySelector(`#view-${originalActiveViewId}`);
    if (originalContainer) {
        originalContainer.style.display = 'block';
    }
    
    // 恢复全局canvas引用
    const originalCanvas = designStore.canvases[originalActiveViewId];
    if (originalCanvas) {
        window.canvas = originalCanvas;
    }
}
```

### 7. 结果展示

在新窗口中创建图片预览界面：

```javascript
const newWindow = window.open('', '_blank');
newWindow.document.write(`
    <html>
        <head><title>导出的图片</title></head>
        <body>
            <h1>所有视图导出结果</h1>
            ${exportedImages.map(img => `
                <div style="margin: 20px 0; border: 1px solid #ccc; padding: 10px;">
                    <h3>${img.viewName}</h3>
                    <p>导出时间: ${img.timestamp}</p>
                    <img src="${img.imageData}" style="max-width: 100%; height: auto;" />
                    <br/>
                    <a href="${img.imageData}" download="${img.viewName}.png">下载图片</a>
                </div>
            `).join('')}
        </body>
    </html>
`);
```

## 错误处理

### 1. 视图切换失败
```javascript
if (!targetContainer) {
    console.warn(`视图容器未找到: view-${view.id}`);
    continue;
}
```

### 2. Canvas实例缺失
```javascript
if (!canvasInstance) {
    console.warn(`Canvas实例未找到: ${view.id}`);
    continue;
}
```

### 3. 图像捕获失败
```javascript
try {
    const imageDataUrl = await captureCanvas(false);
    if (!imageDataUrl) {
        throw new Error('图像数据为空');
    }
} catch (error) {
    console.error(`捕获视图 ${view.id} 失败:`, error);
    continue;
}
```

## 性能优化

### 1. 批量DOM操作
- 一次性隐藏所有视图容器
- 避免频繁的DOM查询

### 2. 异步处理
- 使用 `async/await` 确保操作顺序
- 适当的延迟等待渲染完成

### 3. 内存管理
- 及时清理临时画布
- 避免内存泄漏

## 触发方式

### 1. 按钮触发
**位置：** `public/js/main.js`

```javascript
document.getElementById('renderBtn').addEventListener('click', function() {
    if (document.querySelector('.preview-canvas-container')) {
        // 预览模式
        const imageDataUrl = capturePreviewCanvas();
        // ...
    } else {
        // 多视图模式
        exportAllViewsAsImages();
    }
});
```

### 2. 模式检测
- **单视图模式：** 存在 `.preview-canvas-container` 元素
- **多视图模式：** 不存在 `.preview-canvas-container` 元素

## 依赖关系

### 1. Pinia Store
- `designStore.activeViewId` - 当前激活视图
- `designStore.views` - 所有视图列表
- `designStore.canvases` - Canvas实例映射

### 2. DOM 元素
- `.view-container` - 视图容器
- `#view-{id}` - 特定视图容器
- `#renderBtn` - 导出按钮

### 3. 外部函数
- `getActiveCanvasElements()` - 获取画布元素
- `getActiveCanvas()` - 获取Fabric.js实例
- `captureCanvas()` - 图像捕获函数

## 注意事项

1. **视图切换必须完整**：确保DOM更新和Canvas渲染都完成
2. **状态恢复很重要**：避免影响用户的工作状态
3. **错误处理要全面**：单个视图失败不应影响其他视图
4. **性能考虑**：大量视图时要注意内存使用
5. **异步操作**：确保所有异步操作正确完成

## 扩展性

该架构支持以下扩展：

1. **自定义导出格式**：修改 `captureCanvas()` 支持不同格式
2. **批量下载**：添加ZIP打包功能
3. **导出配置**：支持分辨率、质量等参数配置
4. **进度显示**：添加导出进度条
5. **并行处理**：优化大量视图的处理速度
