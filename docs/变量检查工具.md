# 变量检查工具

## 防冲突命名规范

### SCSS变量前缀规范
项目中的SCSS变量必须使用 `$canvas-` 前缀，以避免与其他插件、主题的变量冲突：

```scss
// ✅ 正确 - 使用 canvas- 前缀
$canvas-primary-color: #3b82f6;
$canvas-spacing-md: 16px;
$canvas-border-radius: 4px;

// ❌ 错误 - 通用变量名容易冲突
$primary-color: #3b82f6;
$spacing: 16px;
$radius: 4px;
```

### 变量命名检查清单
- [ ] 使用 `$canvas-` 前缀
- [ ] 语义化命名（表达用途而非具体值）
- [ ] 避免使用具体颜色名或数值
- [ ] 包含详细的使用说明注释

## 快速检查命令

### Windows PowerShell
```powershell
# 搜索已存在的变量（不区分大小写）
Get-Content "public\css\_variables.scss" | Select-String "\$canvas-" | Sort-Object

# 检查特定关键词的变量
Get-Content "public\css\_variables.scss" | Select-String "color|背景|按钮" 

# 搜索特定颜色值
Get-Content "public\css\_variables.scss" | Select-String "#3b82f6|#ef4444"
```

### Linux/Mac
```bash
# 搜索已存在的变量
grep '\$canvas-' public/css/_variables.scss | sort

# 检查特定关键词的变量  
grep -i "color\|背景\|按钮" public/css/_variables.scss

# 搜索特定颜色值
grep "#3b82f6\|#ef4444" public/css/_variables.scss
```

## 变量命名规范检查清单

### 1. 命名前缀检查
- [ ] 使用 `$canvas-` 前缀
- [ ] 避免使用 `$color-`、`$size-` 等通用前缀

### 2. 语义化命名检查
```scss
// ✅ 好的命名
$canvas-primary-color: #3b82f6;      // 语义清晰
$canvas-error-color: #ef4444;        // 表达用途
$canvas-spacing-md: 16px;            // 大小层级明确

// ❌ 避免的命名
$canvas-blue: #3b82f6;               // 不要用具体颜色名
$canvas-red: #ef4444;                // 不表达用途
$canvas-16px: 16px;                  // 不要用数值命名
```

### 3. 分类检查
确保新变量放在正确的分类区域：
- 颜色变量 → Colors 区域
- 尺寸变量 → Dimensions 区域  
- 间距变量 → Spacing 区域
- 字体变量 → Typography 区域
- 阴影变量 → Shadows 区域
- 动画变量 → Animations 区域

## 常用变量快速参考

### 颜色变量
```scss
$canvas-primary-color: #3b82f6;        // 主色调
$canvas-secondary-color: #64748b;      // 次要色调
$canvas-success-color: #22c55e;        // 成功状态
$canvas-warning-color: #f59e0b;        // 警告状态
$canvas-error-color: #ef4444;          // 错误状态
$canvas-bg-color: #ffffff;             // 主背景
$canvas-bg-secondary: #f8fafc;         // 次要背景
$canvas-border-color: #e2e8f0;         // 边框颜色
```

### 间距变量
```scss
$canvas-spacing-xs: 4px;               // 超小间距
$canvas-spacing-sm: 8px;               // 小间距
$canvas-spacing-md: 16px;              // 中等间距
$canvas-spacing-lg: 24px;              // 大间距
$canvas-spacing-xl: 32px;              // 超大间距
```

### 尺寸变量
```scss
$canvas-border-radius: 4px;            // 标准圆角
$canvas-border-radius-sm: 2px;         // 小圆角
$canvas-border-radius-lg: 8px;         // 大圆角
```

### 字体变量
```scss
$canvas-font-size-sm: 12px;            // 小文字
$canvas-font-size-base: 14px;          // 标准文字
$canvas-font-size-lg: 16px;            // 大文字

```

## 添加新变量的标准流程

### 1. 检查阶段
```bash
# 步骤1: 搜索相似变量
grep -i "你要添加的关键词" public/css/_variables.scss

# 步骤2: 检查相似颜色值
grep "你要添加的颜色值" public/css/_variables.scss

# 步骤3: 确认分类区域
# 查看 _variables.scss 文件，确定新变量应该放在哪个分类区域
```

### 2. 添加阶段
```scss
// 在对应分类区域添加新变量
// 变量用途描述 - 用于具体说明
// 使用位置：详细说明在哪些组件/页面中使用
$canvas-new-variable: value;
```

### 3. 验证阶段
- [ ] 变量名符合命名规范
- [ ] 添加了详细的注释说明
- [ ] 放在了正确的分类区域
- [ ] 在实际组件中测试使用
- [ ] 编译 SCSS 无错误

## 变量重构指南

### 发现重复变量时
```scss
// 如果发现类似的变量
$existing-var: #3b82f6;
$new-var: #3b82f6;

// 应该：
// 1. 评估两个变量的用途
// 2. 选择更语义化的名称
// 3. 统一使用一个变量
// 4. 更新所有引用的地方
```

### 变量重命名流程
1. 在 `_variables.scss` 中重命名变量
2. 搜索所有使用该变量的 SCSS 文件
3. 批量替换变量名
4. 编译测试确保无错误
5. 更新相关文档

## 自动化工具建议

### VS Code 扩展推荐
- **SCSS IntelliSense**：提供变量自动完成
- **Live Sass Compiler**：实时编译 SCSS
- **Color Highlight**：高亮显示颜色值

### 自定义代码片段
在 VS Code 中添加 SCSS 变量模板：

```json
{
  "SCSS Variable": {
    "prefix": "canvas-var",
    "body": [
      "// ${1:变量用途描述} - 用于${2:具体说明}",
      "// 使用位置：${3:详细说明使用位置}",
      "\\$canvas-${4:variable-name}: ${5:value};"
    ],
    "description": "添加新的 Canvas 变量"
  }
}
```
