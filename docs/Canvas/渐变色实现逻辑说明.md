# 渐变色功能实现逻辑说明

## 功能概述

渐变色功能是设计页面的核心功能之一，允许用户为产品的Base图层应用线性渐变色效果。该功能采用Fabric.js的渐变覆盖层技术，结合智能裁剪实现精确的渐变色上色。

## 技术架构

### 核心技术栈
- **Fabric.js**: 2D画布渲染和渐变对象创建
- **Canvas API**: 渐变坐标计算和渲染
- **globalCompositeOperation**: 智能裁剪技术
- **MicroModal**: 弹窗组件管理
- **Pinia Store**: 状态管理

### 关键设计原理
- **渐变覆盖层**: 创建与Base图层完全重合的渐变矩形
- **智能裁剪**: 使用`source-in`合成模式只在非透明区域显示渐变
- **多画布支持**: 同时支持设计页面和产品页面环境
- **状态同步**: 通过Pinia store管理渐变应用状态

### 2. 渐变色应用逻辑
**位置**: `pwca-gradient-modal.php` 第235-476行

#### 应用流程
1. **环境检测**: 判断是设计页面还是产品页面
2. **画布获取**: 获取正确的baseCanvas实例
3. **清除旧渐变**: 调用`clearAllGradientRects()`清除已有渐变
4. **创建渐变对象**: 使用Fabric.js创建线性渐变
5. **创建覆盖层**: 创建渐变矩形并设置裁剪模式
6. **图层管理**: 确保正确的图层顺序

#### 核心代码逻辑
```javascript
// 获取baseCanvas实例
const baseCanvasId = `baseCanvas-${activeViewId}`;
const baseCanvas = window.CanvasManager.getCanvas(baseCanvasId) || 
                  (document.getElementById(baseCanvasId) && document.getElementById(baseCanvasId).__fabricCanvas);

// 创建渐变对象
const gradient = new fabric.Gradient({
    type: 'linear',
    coords: gradientCoords,
    colorStops: [
        { offset: 0, color: color1 },
        { offset: 1, color: color2 }
    ]
});

// 创建渐变覆盖层
const overlayRect = new fabric.Rect({
    left: baseLayerObject.left,
    top: baseLayerObject.top,
    width: baseLayerObject.width,
    height: baseLayerObject.height,
    fill: gradient,
    globalCompositeOperation: 'source-in', // 智能裁剪
    name: 'Base Gradient Overlay',
    id: 'gradient-rect-' + Date.now()
});
```

### 3. 渐变色清除功能
**文件**: `public/partials/canvas-design_area.php`
**函数**: `clearAllGradientRects()` (第1150-1210行)

#### 清除逻辑
```javascript
window.clearAllGradientRects = function() {
    // 获取baseCanvas实例
    const baseCanvasId = `baseCanvas-${activeViewId}`;
    const baseCanvas = window.CanvasManager.getCanvas(baseCanvasId) || 
                      (document.getElementById(baseCanvasId) && document.getElementById(baseCanvasId).__fabricCanvas);
    
    // 查找并移除渐变对象
    const objectsToRemove = [];
    baseCanvas.getObjects().forEach(obj => {
        if ((obj.id && obj.id.startsWith('gradient-rect-')) ||
            (obj.name && obj.name === 'Base Gradient Overlay')) {
            objectsToRemove.push(obj);
        }
    });
    
    // 移除对象并重新渲染
    objectsToRemove.forEach(obj => baseCanvas.remove(obj));
    baseCanvas.renderAll();
};
```

## 渐变方向支持

### 支持的方向类型
1. **to right**: 从左到右
2. **to left**: 从右到左  
3. **to bottom**: 从上到下
4. **to top**: 从下到上
5. **to bottom right**: 从左上到右下
6. **to bottom left**: 从右上到左下
7. **to top right**: 从左下到右上
8. **to top left**: 从右下到左上

### 坐标计算逻辑
```javascript
function getLinearGradientCoords(direction, width, height) {
    const coords = {};
    switch (direction) {
        case 'to right':
            coords.x1 = 0; coords.y1 = height / 2;
            coords.x2 = width; coords.y2 = height / 2;
            break;
        case 'to bottom':
            coords.x1 = width / 2; coords.y1 = 0;
            coords.x2 = width / 2; coords.y2 = height;
            break;
        // ... 其他方向
    }
    return coords;
}
```

## 智能裁剪技术

### 核心原理
使用Canvas的`globalCompositeOperation: 'source-in'`属性实现智能裁剪：
- **source-in**: 新图形只在与现有图形重叠的地方绘制
- **效果**: 渐变色只在Base图层的非透明像素区域显示
- **优势**: 完美贴合产品轮廓，无需复杂的路径计算

### 图层顺序管理
```javascript
// 确保正确的图层顺序
baseCanvas.sendToBack(baseLayerObject);      // Base图层在底层
baseCanvas.bringForward(overlayRect);        // 渐变覆盖层在中层
if (overlayLayerObject) {
    baseCanvas.bringToFront(overlayLayerObject); // Overlay图层在顶层
}
```

### 常见问题排查
1. **渐变不显示**: 检查baseCanvas是否正确获取
2. **渐变无法清除**: 验证`clearAllGradientRects`函数是否正常工作
3. **图层顺序错误**: 检查`sendToBack`和`bringForward`调用
4. **裁剪效果异常**: 验证`globalCompositeOperation`设置

## 性能优化

### 1. 对象标识优化
- 使用唯一ID标识渐变对象：`gradient-rect-${timestamp}`
- 使用固定name标识：`Base Gradient Overlay`
- 便于快速查找和清除

### 2. 事件处理优化
- 颜色选择事件只初始化一次
- 使用标记变量避免重复绑定
- 弹窗关闭时重置状态

### 3. 画布渲染优化
- 批量操作后统一调用`renderAll()`
- 避免频繁的画布重绘
- 合理管理图层顺序
