# 设计页视图状态恢复重建规范

## 适用范围

- `modules/front_canvas/assets/js/design/stores/view-state-rebuild-helper.js`
- `modules/front_canvas/assets/js/design/utils/canvas-state-manager.js`
- `modules/front_canvas/assets/js/design/stores/view-restore-helper.js`

## 职责边界

- `view-state-rebuild-helper.js` 负责：
  - 从恢复输入的 `layers / layerGroups / canvas` 重建最终恢复 payload
  - 当画布对象已有数据但 `layers` 缺失时，从画布对象重建图层列表
  - 当 `layers` 存在但画布对象缺少元数据时，把 `id / layerName / layerType / groupId / groupOrder` 回填到对象
- `view-restore-helper.js` 负责：
  - 对重建后的 payload 做最终标准化
- `canvas-state-manager.js` 负责：
  - 调用重建 helper
  - 将重建结果写入 store

## 设计原则

- `canvas-state-manager` 不直接内嵌大段图层重建逻辑
- 图层重建与 payload 标准化分层处理：
  - 先重建
  - 再标准化
- 恢复算法不改变原有业务含义，只调整职责分布

## 重建规则

- 如果 `layers` 与画布对象都存在：
  - 按顺序把图层元数据回填到画布对象
- 如果 `layers` 缺失但画布对象存在：
  - 从非背景对象重建图层数组
  - 自动补 `id`
  - 自动推导 `name`
  - 自动推导 `type`
- 最终返回值必须继续经过 `pwcaNormalizeViewRestorePayload`

## 兼容要求

- 不改变 `layerName / layerType / groupId / groupOrder` 的现有字段语义
- 不改变背景对象过滤规则
- 保留 `window.pwcaRebuildViewRestorePayload` 给非模块脚本复用
