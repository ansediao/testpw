## 目标

- 减少外围脚本重复直接读取 `window.useCanvasStore()`、`window.usePrintMethodStore()`、`window.CanvasManager`
- 统一“当前视图 / 当前画布 / 当前产品 variants / 当前对象印刷方式”的读取入口

## 共享访问层

- 统一通过 `window.pwcaUiStateAccess` 访问共享状态
- 当前已提供：
  - `getCanvasStore()`
  - `getPrintMethodStore()`
  - `getActiveViewId()`
  - `getViews()`
  - `findViewById(viewId)`
  - `getCurrentView()`
  - `getProductVariants()`
  - `hasProductVariants()`
  - `getCanvasByViewId(viewId)`
  - `getBaseCanvasByViewId(viewId)`
  - `getAllViewIds()`
  - `getAllViewCanvases()`
  - `getActiveCanvas()`
  - `getActiveObject()`
  - `getCurrentActiveTab()`
  - `getActiveObjectType()`
  - `getCurrentBaseCanvas()`
  - `getCurrentViewLayers()`
  - `findCurrentViewLayerById(layerId)`
  - `getPrintMethodForObject(obj)`
  - `isFirstView(viewId)`

## 设计原则

- 外围脚本优先走 `pwcaUiStateAccess`
- 只有共享访问层尚未覆盖的场景，才允许临时直接访问全局对象
- 新增外围脚本时，禁止再复制一套 store / canvas / view 获取逻辑
- 若多个脚本出现相同的全局读取模式，应先补充到 `ui-state-access.js`

## 当前接入范围

- `toolbar.js`
  - 文字字体列表读取
  - 当前激活画布读取
  - 当前对象印刷方式读取
- `layers-sync.js`
  - Canvas store 获取
  - 当前视图 ID 获取
  - 当前激活画布获取
  - 当前视图图层查找
  - PrintMethod store 获取
- `operation-panel-colors.js`
  - Canvas store 获取
  - 当前视图获取
  - 产品 variants 获取
  - 当前激活画布获取
  - 当前视图是否首视图判断
  - base canvas 获取
- `operation-panel-tabs.js`
  - 多视图画布列表获取
  - 当前激活画布获取
  - tab 切换时统一清理选区
- `preview.js`
  - 当前激活画布获取
  - Canvas store 获取
  - 多视图画布列表获取
- `page-bootstrap.js`
  - Canvas store 获取
  - 多视图画布列表获取
  - 提交前统一清理各视图选中状态
- `tab-text.js`
  - Canvas store 获取
  - 当前激活画布获取
- `tab-image.js`
  - Canvas store 获取
  - 当前激活画布获取
  - 当前激活视图刷新
- `header-controls.js`
  - 按视图获取 canvas
  - 多视图画布列表获取
  - 预览前统一清理各视图选区
- `canvas-state-integration.js`
  - Canvas store 获取
  - PrintMethod store 获取
  - 当前激活视图 ID 获取
  - 按视图获取 canvas
  - 恢复链中的状态读取统一走共享访问层
- `canvas-state-manager.js`
  - Canvas store 获取
  - PrintMethod store 获取
  - 当前激活视图 ID 获取
  - 全部视图 ID 获取
  - 按视图获取 canvas
  - 状态保存与恢复链统一走共享访问层
- `customization-area.js`
  - Canvas store 获取
  - 视图按钮初始化前的 store 等待统一走共享访问层
- `url-params-handler.js`
  - Canvas store 获取
  - views 获取
  - 当前激活视图 ID 获取
  - URL 视图切换与编辑态初始化统一走共享访问层
- `core-init.js`
  - Canvas store 获取
  - 当前激活视图 ID 获取
  - 多视图 canvas 列表获取
  - 操作面板 tab 切换前的选区清理统一走共享访问层
- `capture.js`
  - 按视图获取 canvas
  - PrintMethod store 获取
  - 导出链中的视图画布读取统一走共享访问层
- `view-switch-facade.js`
  - Canvas store 获取
  - views 获取
  - 当前激活视图 ID 获取
  - 按视图获取 canvas
  - 多视图选区清理统一走共享访问层
- `grid-preview.js`
  - 按视图获取 canvas
  - 当前激活画布获取
  - 网格预览截图链统一走共享访问层
- `operation-panel-design-search.js`
  - Canvas store 获取
  - 设计分类可见性跟随当前视图切换统一走共享访问层

## 迭代原则

- 本阶段只做“共享读取入口”收口，不一次性改完所有外围脚本
- 后续可继续把剩余的 `CanvasManager`、`useCanvasStore` 直接读取逐步迁移到 `pwcaUiStateAccess`
- 产品页 fallback 与非设计页历史兼容逻辑允许暂时保留，不强行一次性移除
