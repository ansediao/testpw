# PW Canvas 防冲突迁移指南

## 概述

本指南提供将现有 PW Canvas 代码迁移到防冲突命名规范的具体步骤、策略和最佳实践。

## 迁移策略

### 渐进式迁移原则

1. **保持向后兼容** - 避免破坏现有功能
2. **优先级驱动** - 先处理高风险冲突
3. **批量处理** - 同类问题一次性解决
4. **充分测试** - 每个阶段都要验证功能正常

### 迁移阶段规划

#### 阶段 1: 高风险项目（立即执行）
- [ ] 全局 JavaScript 函数
- [ ] 主要 CSS 类名和 ID
- [ ] 自定义事件名称

#### 阶段 2: 中风险项目（2周内完成）
- [ ] WordPress 钩子名称
- [ ] Ajax 动作名称
- [ ] REST API 端点

#### 阶段 3: 低风险项目（1个月内完成）
- [ ] 内部变量重命名
- [ ] 文档更新
- [ ] 清理临时兼容代码

## 批量迁移工具

### 1. 查找替换脚本

#### PowerShell 脚本
```powershell
# CSS 类名批量替换
$replacements = @{
    '\.canvas-container\b' = '.pwca-canvas-container'
    '\.toolbar\b' = '.pwca-toolbar'
    '\.layer-panel\b' = '.pwca-layer-panel'
    '#main-canvas\b' = '#pwca-main-canvas'
}

Get-ChildItem -Path "modules\", "includes\" -Recurse -Include "*.scss", "*.css", "*.php", "*.js" | 
    ForEach-Object {
        $content = Get-Content $_.FullName -Raw
        $modified = $false
        
        foreach ($pattern in $replacements.Keys) {
            if ($content -match $pattern) {
                $content = $content -replace $pattern, $replacements[$pattern]
                $modified = $true
            }
        }
        
        if ($modified) {
            Set-Content $_.FullName $content
            Write-Host "Updated: $($_.FullName)" -ForegroundColor Green
        }
    }
```

#### Linux/Mac 脚本
```bash
#!/bin/bash

# JavaScript 函数名批量替换
declare -A replacements=(
    ["function init("]="function pwcaInit("
    ["function saveState("]="function pwcaSaveState("
    ["function exportImage("]="function pwcaExportImage("
)

for file in $(find modules includes -name "*.js"); do
    for old in "${!replacements[@]}"; do
        new="${replacements[$old]}"
        if grep -q "$old" "$file"; then
            sed -i "s/$old/$new/g" "$file"
            echo "Updated: $file"
        fi
    done
done
```
