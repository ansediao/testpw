# PW Canvas 项目概述

## 项目目的
PW Canvas 是一个基于 WordPress 的插件，用于提供在线产品定制功能。该插件允许用户在网页上进行产品设计和定制，主要面向电商场景中的个性化产品定制需求。

## 核心功能
- **在线画布设计**: 基于 Fabric.js 的 2D 画布编辑器
- **3D 模型预览**: 使用 Three.js 进行 3D 产品展示
- **产品变体管理**: 支持颜色、尺寸等产品变体选择
- **购物车集成**: 与 WooCommerce 深度集成
- **设计管理**: 自定义文章类型 `pw_design` 用于管理设计模板
- **API 集成**: 与 Promowares API 进行数据交互

## 技术特点
- WordPress 插件架构
- 前后端分离设计
- 响应式 Web 应用
- 支持实时预览和导出功能

## 依赖要求
- WordPress 环境
- WooCommerce 插件
- Flamingo 插件
- PHP 5.6+ 兼容性
